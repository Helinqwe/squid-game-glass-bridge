# 🪟 Glass Bridge Game (Squid Game)

A simple and fun terminal game where you have to choose the right glass pane to cross the bridge.

## How to play
- You see two rows of 10 glass panes.
- One row is safe ('■'), the other is fragile ('=').
- Choose the correct pane to survive!
- If you choose wrong, you lose one life and break the glass.

## How to run
1. Make sure you have Python 3 installed.
2. Run the script:
   ```bash
