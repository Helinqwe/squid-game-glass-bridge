# 🪟 Стеклянный мост (Игра в кальмара)

Простая, но напряженная консольная игра по мотивам культового сериала "Игра в кальмара".  
Ваша цель — пройти по стеклянному мосту из 15 плит, выбирая между верхним и нижним рядом. Один ряд безопасный, другой — смертельно опасный. Ошибаться нельзя... ну, или можно, но ценой чужой жизни.

---

## 🎮 Как играть

- Перед вами мост из 10 пролетов.
- В каждом пролете есть **верхняя** и **нижняя** плита.
- Одна плита прочная (`■`), другая — хрупкая (`=`) и разбивается.
- Выбирайте плиту и надейтесь, что она выдержит!
- За каждую ошибку погибает один человек. Ваша совесть будет с вами.

---

## 🕹️ Управление

- Нажмите `1` — прыгнуть на **верхнюю** плиту.
- Нажмите `2` — прыгнуть на **нижнюю** плиту.

---

## 🚀 Как запустить

1. Убедитесь, что у вас установлен **Python 3** (любой версии).
2. Скачайте файл `glass_bridge.py`.
3. Откройте терминал/командную строку в папке с файлом.
4. Выполните команду:

```bash
python glass_bridge.py
```
